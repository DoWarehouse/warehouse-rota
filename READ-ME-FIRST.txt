# Packing station pairs - 23 November 2026

This update adds daily Packing positions such as 1A/1B and 2A/2B, separately for Warehouse 1 and Warehouse 2. It includes the FTE summary and weekly shift reference from the previous updates.

## Keep the existing rota data

Before updating, sign in as manager and open **Settings (sliders icon) -> Download data backup**. This downloads a complete SQLite copy of the current rota.

Keep the same Render service, persistent disk, DATA_DIR=/var/data, environment values and GitHub folder structure. This package contains application code only: no database, demo data or reset command. Updating it does not replace any colleague, shift, attendance record, holiday balance, required hours, dashboard connection, published rota or QR token.

The first updated start adds a packing_stations table and two optional shift fields. Existing shifts remain unassigned to stations; no assignments are guessed. Before upgrading a populated database from schema 6, the app makes **/var/data/backups/rota-before-schema-7.sqlite**. The upgrade is additive and runs once.

## Set up and use stations

1. Open **Day** view and find **Packing -> Manage stations**, or use **Settings -> Packing stations**.
2. Choose **Warehouse 1** and enter a range of station numbers, for example **1 to 4**. This creates 1A/1B, 2A/2B, 3A/3B and 4A/4B. Repeat for Warehouse 2 using its own numbers. Re-adding existing numbers keeps them; archived numbers can be restored.
3. Drag a colleague's saved Packing shift from **Unassigned Packing shifts** into the desired A/B position. Alternatively, use **Choose shift** in a position; this also works on phones. The single-shift editor has an optional **Packing position** selector.
4. A and B are shown together under the same station and warehouse. Their times remain visible. A warning identifies a station when its A/B shifts do not overlap. Overnight assignments show the next morning as **Until [finish time] - from [previous day]**.
5. **Publish** the week when ready. Colleagues using the existing QR code can open Day view to see their station and partner. Weekly shift cards, the editor's weekly reference, PDFs and CSV exports show the position label too. Draft position changes remain private until publishing.

Assigning a position changes only that shift's station and A/B field. It does not change the colleague, date, type, hours, breaks, labels, notes or attendance. Picking and Engraving remain separate departments. Packing stays Packing; stations are not new departments or colleague profile roles.

An A/B position cannot contain overlapping shifts, including overnight overlaps. Different non-overlapping shifts can use the same position during the day. A no show retains its planned position until you explicitly unassign it. Warehouse and location must match the shift. A position never overwrites another person's shift.

**Unassign position**, or drag to **Drop here to unassign a position**, removes only the station assignment and keeps the full shift. Station **Archive** retains historical assignments and is blocked while current/future assignments remain. There is no station-delete action.

Copy day/week preserves the original shifts and their pairings. The newly copied shifts start with no station assignment, ready to pair for the new day. Name search filters the unassigned list; the station board keeps both partners visible. Warehouse and department filters still apply.
